# 第四轮验证设计
开发阶段使用先前 C 几何筛选了误差驱动节点、细网格修正、PCG 轨迹以及约束能量平滑。正式数据使用 validate.py 中另行指定的几何和随机种子。四胞涡是本轮新增的场族。各案例、全部方法、顺序及代码哈希在求解前锁定。

候选方法用已有 Pmax=8 V-cycle，辅助网格每方向缩小四倍。用随机种子91开始 A 内积 Arnoldi。第12步最小 Ritz 值低于0.08则沿用已有向量继续求两条慢坐标，否则直接使用细网格 Boomer。开发时 n=511 的中等各向异性和多数简单场的粗估计偏大，薄带是已知可能误触发的情形。该阈值是开发参数。通过后使用原有相对 Ritz 残差阈值0.1、最多128步，延拓后各做一次 v←v−BAv，并在两个坐标各自的值域使用等距帽函数。删去各坐标最接近零的帽函数，采用已实现的平衡两层补偿。无初始细网格 PCG，最终从零开始求解。

六个目标案例及三个控制案例。每例三次，各重复块内方法乱序、每个任务使用单独进程、同一计算线程。主比较是候选对上轮沿用的原版自适应方案 old。raw 只关闭两次细网格坐标修正。fine_pilot_aligned 保留旧的细网格门控、采用相同的非加权帽函数及细网格修正。两个原生 Boomer 配置用于全部案例，六个目标案例额外运行无门控的96步非加权帽函数和96步直接16模态。逐例取各方法总时间中位数，再对案例的比值取中位数。总时间包含建立、探测、补偿和求解，排除装配和独立 double-double 残差复算。迭代上限1500，真实相对残差≤1e−8。发生失败则保存，并单列。

保留完整替代方案的开发判断标准为六个目标案例至少四例快于 old、中位时间至少降低10%、三个控制案例各自比更快的原生 Boomer 回退至多10%。分别报告不达标的条件。单独评估坐标修正效应时只使用触发的案例。三次重复支持机器上的点估计。固定96步允许考察更强的历史对手。此轮没有重复第三轮全部调参，不作全面最优声明。
