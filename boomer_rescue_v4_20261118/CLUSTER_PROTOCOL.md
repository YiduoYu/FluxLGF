# 成簇慢模态的两坐标编码试验

这是在发现原四胞涡的32/96步异常后提出的后续试验。四组几何参数均新选定，场族已经用于发现。两次重复，单线程、分块乱序、独立进程。方案和顺序在读取新算例结果前锁定。与主实验分开统计。

固定96步求辅助网格最小5个Ritz对。与最小特征值比值≤1.2者入簇，至多4个。少于3个时沿用前两条。若有3至4个，对簇基矩阵的转置做带列主元QR，以选出的m个网格点为锚，将它们按选择次序映射到单位圆上m个等距点，求出两组混合系数。每个细网格生成坐标只做一次Boomer修正，沿用均匀值域帽函数。

对照含同预算96步前两个模态、同簇直接逐坐标展开并均分基函数列预算、无锚的随机二坐标投影和主实验的早停方案。所有96步方法均抽取5个Ritz对并显式检查。列预算保持相同，整数取整可少至m−1列，实际非零列数单列。无锚随机投影种子固定。记录建补偿到收敛的总时间及独立真实残差。

有意义的支持须在至少3/4个参数案例上比固定96步前两个模态减少迭代，且相对此对照的逐例总时间比中位数<0.90。是否优于现有早停方案、随机混合、直接展开为独立问题，均完整报告。这是单场族先导试验，不能替代跨场族复验。
