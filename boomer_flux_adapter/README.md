# 用九点模板恢复闭合场线，给 BoomerAMG 加一个粗空间

研究对象为二维标量、强各向异性扩散，单位正方形规则网格，零 Dirichlet 边界，内部自由度按行排列。面向这类输入的入口是 `StencilFluxAdapter(A, base, n)`。如果模型已经给出含边界的节点流函数，可以直接用 `FluxAdapter(A, base, psi)`。两种接口都保留原生 Boomer 周期，基于同一个离散矩阵求解。实现和实验位于本目录，历史实验保留各自的入口。

## 本机结果与投入判断

**建议把模板恢复版作为二维闭合场线问题的可选 adapter。** 六个目标案例中，它相对逐例更快的 P4/P8 赢 6/6，中位总时间节省 52.6%。相对 V4 主方案赢 6/6，中位节省 45.0%。三个控制相对较快原生配置的时间比分别为 1.145、1.010、1.004。解析通量版本在第一批的六个目标上中位节省 60.3%。两个实验的九个输入相同，不能把它们当作十八个独立案例。

### 哪个问题值得继续

优先解决**如何识别内部岛以及决定哪些岛值得补偿**。用二维等值线的连通分支和鞍点识别局部闭合族，可在边界值域内保留独立剖面。应以上述内部岛和新的合并、分裂场作预先指定的验证，新增的区域检测成本也要计入。另一个可测的限制是方向拟合误差。在均匀各向异性下，沿强方向的附加能量与 (χ−1)η² 成正比，η 为归一化方向缺陷。六胞案例可用于比较按能量误差选拟合阶数与现有固定容差。文献级评估还需在相同矩阵和停止条件下，与局部谱两层算法以及线平滑方法进行实测。

## 构造

1. 在两套互不共享节点的 31×31 采样格上，取内点完整九点模板。用二阶矩 `-Σⱼ Aᵢⱼ δᵢⱼ δᵢⱼᵀ` 估计局部扩散张量的主轴。δ 取格点偏移，公共比例因子不影响主轴。对角反应项也不影响。对系数快速变化和离散交叉项，二阶矩只是估计。强各向异性占比不足即返回底座。
2. 在张量积 Legendre 多项式中拟合第一积分 ψ，即沿一条场线保持常值的标量。沿主轴 e 的导数应很小，因此最小化 `Σ(e·∇ψ)² / Σ|∇ψ|²`，去掉常数，加入微小的高阶系数惩罚。用独立节点检查方向缺陷，取首个通过的阶数。这里解的是字典系数的小广义特征问题，无需辅助 PDE、细网格 Boomer 慢特征向量或右端项。检查值衡量沿场导数，不能保证拓扑恢复正确。
3. 找出 ψ 高于整个边界最大值或低于最小值的内点，按四邻域分区。每区把离阈值的深度归一化到 [0,1]，在该坐标上构造独立的三次 B 样条，去掉在零端点非零的基函数。按区内点数平方根分配总列数。扁平剖面用 Gram 谱检查减少列数。单点至多参与四个粗基函数。这里对边界值域的检测是一个充分筛选条件，无法枚举全部闭合等值线。
4. 复用项目的平衡两层补偿。设 `Q=Z(ZᵀAZ)⁻¹Zᵀ`，新预条件器为 `Q+(I-QA)B(I-AQ)`。若 A 和底座 B 对称正定且 Z 列满秩，此式在精确算术下对称正定，可直接接 PCG。每次仅调用一个原生 Boomer 周期。每行四项只对 Z 成立，AZ 和粗分解另占内存。

慢误差机制可以用链式法则解释。在第 j 个闭合区内，若误差为 gⱼ(ψ)，则沿强扩散方向的导数为 gⱼ′(ψ)e·∇ψ。当两个涡胞共享同一个 ψ 值，强迫它们使用同一个 g 会漏掉区域间独立的误差。每区单独分配系数，允许两处取不同的修正值。这一解释只涉及误差子空间。复杂场中还可能有依赖沿线位置的慢误差。

## 文献边界

闭合磁场线上的常值函数与极限问题的退化结构已有理论和离散方法。针对极端各向异性热流，Vasilyeva、Wimmer、Southworth 已用局部广义特征问题构造场线对齐的两层预条件器。用方向导数的零空间识别守恒量也有先例。本次值得研究的增量是**由细网格模板恢复第一积分，以独立的通量分区在有限列预算下修补现有 Boomer**。本轮只与仓库可运行的强方法比较。论文优先性、对公开方法的优势和一般条件数界都尚待验证。[闭合场线方法](https://arxiv.org/abs/1610.09370) · [局部谱两层方法](https://arxiv.org/abs/2412.08355) · [守恒量识别](https://arxiv.org/abs/1811.00961)

## 接入与复现

在项目根目录执行。仓库已有 Boomer 类负责 PETSc 对象的生命周期。adapter 接受并复用已建的 `base`。以下示例用仓库现有 PCG，可将 A、b 和 n 换成满足上述前提的输入。调用方在 PCG 开始前固定 adapter，计算完毕后关闭底座。

```python
from boomer_flux_adapter.recover import StencilFluxAdapter
from experiment import Boomer, problem, solve

n = 127
A, b, _ = problem("circ", n, 1e5, [.57, .28, .43])
base = Boomer(A, "p8")
try:
    M = StencilFluxAdapter(A, base, n, budget=(n+1)//4)
    x, iterations, ok, _, message = solve(A, M, b)
    print(M.fit, M.regions, M.columns, iterations, ok, message)
finally:
    base.close()
```

环境为 Python 3.10.22、NumPy 2.2.6、SciPy 1.15.2、PETSc 3.25.6、单进程单线程。核对实际 PETSc PC view，两组基线均为 HMIS、ext+i、强连接阈值 0.25、上下对称 SOR/Jacobi、每次调用一个 V-cycle，插值行上限分别为 4、8。预设目标和时间口径见 [解析通量方案](PROTOCOL.md) 与 [模板恢复方案](RECOVERY_PROTOCOL.md)。
